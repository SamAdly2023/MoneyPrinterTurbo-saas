Create an OAuth Web application client in Google Cloud (enable “YouTube Data API v3”), add the redirect URI below, add yourself as a test user, then paste the ID/secret here. This is the shared OAuth app - each user still connects their own channel from the Dashboard.

Publishing — TikTok (needs app audit for auto-post)

From TikTok for Developers. Without an approved audit, videos are sent to your TikTok drafts. TikTok requires an https redirect URI, so set the base URL (e.g. an ngrok https URL) below.
